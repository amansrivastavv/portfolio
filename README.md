# 🌟 Aman Srivastav - 3D Front-End Portfolio

Explore my interactive front-end playground built using **React**, **Vite**, and **Three.js**, featuring immersive 3D elements powered by WebGL.

**🔗 Live demo:** [amansrivastavv.github.io/portfolio/](https://amansrivastavv.github.io/portfolio

## 🚀 Tech Stack

- **React** – Modular UI components and state management  
- **Vite** – Fast build tool for superior development experience  
- **Three.js** – Creates 3D scenes, animations, and visual effects  
- **React Three Fiber**– Bridges React and Three.js for declarative canvas  
- **Framer Motion** – Smooth transitions and hover effects  
- **Bootstrap** – Quick layout and responsive design utilities  
- **Custom CSS** – Fine-tuned styling for polished presentation  
- **GitHub Pages** – Free hosting with seamless deployment

---

## ✨ Features

- 🎥 **3D Background Effects** – Subtle interactive animations (like raindrops or moving objects) that respond to mouse movement, creating depth and engagement  
- 🔄 **Smooth Scroll & Parallax** – Camera or scene movement tied to scroll for immersive feel  
- 🧑🏻‍💻 **Hero Intro** – Animated hero section with professional photo and tagline, perfectly setting the tone  
- 📁 **Project Showcase** – Highlights of your work with interactive visuals  
- 📬 **Contact Form** – Easy-to-use and accessible form for recruiting or networking purposes
