# 👋 Hey there, I'm Aman Srivastav!

Welcome to my personal portfolio website — a space where I showcase my work, skills, and everything I’ve been building as a Front-End Developer. If you're here to know what I do or looking to collaborate — you're in the right place.

🔗 **Live Site**: [amanfrontend.vercel.app](https://amanfrontend.vercel.app)

## 🛠️ Tech Stack I Used

I built this portfolio using a blend of modern tools and libraries:

- **React** – For building dynamic UI components.
- **Vite** – Blazing fast bundler to keep my development workflow smooth.
- **Framer Motion** – For slick animations like hero fades, transitions, and scroll effects.
- **Locomotive Scroll** – Adds that buttery-smooth scrolling with inertia and parallax vibes.
- **Bootstrap** – For responsive grids and utility-first styling.
- **Custom CSS** – To fine-tune every detail and achieve that unique look.
- **GitHub API** – To fetch and display my latest repositories in real-time.
- **Vercel Analytics** – To track site visits and performance.
